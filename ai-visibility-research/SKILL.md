# Видимость в ИИ-ответах: исследование для РФ

Цель — дополнительный бесплатный трафик: чтобы ассистенты называли и цитировали сайт по нужным запросам.

**Приоритет — российские сервисы:** Алиса AI (блок в выдаче ya.ru и отдельный чат Алисы), GigaChat, затем DeepSeek (массово используется в РФ). ChatGPT, Perplexity, Google — вторым кругом. Советы из западных источников (Reddit, Quora, Google-факторы) проверять на применимость к РФ.

Результат — проверенное исследование и план, а не правки. **Ничего не меняем на сайтах и в кабинетах, пока исследование не закончено и план не согласован с пользователем.**

Текущее знание (что установлено и что опровергнуто, с датами и уровнем доказательности) — `references/knowledge.md`. Прочитай его первым и перепроверяй то, что старше 3 месяцев.
Готовые постановки для агентов — `references/agent-briefs.md`.

## 0. Вход и режим

Спроси одним сообщением только то, без чего нельзя начать:
- **Сайты** (0–N): URL, что за продукт, где ведётся код (этот компьютер / другой / не знаю). Без сайтов скилл работает по нише.
- **Ниша и регион**, если сайтов нет. Регион выдачи по умолчанию — Москва (`lr=213`), Вордстат — вся Россия.
- **Материалы пользователя** (опционально): статьи, ответы других нейросетей (share-ссылки), свои гипотезы — их сверяем, а не принимаем на веру.
- **Доступы** — определяют режим:
  - **полный**: браузер пользователя с подключением к Claude Code (Яндекс, Вордстат, Вебмастер, чаты ИИ), по желанию — SSH к логам;
  - **без доступа**: только веб-поиск и curl. Тогда этапы 1, 6, 7 и анализ — сами; живую выдачу, Вордстат, кабинеты и чаты — как готовый список запросов и таблица, которую пользователь заполнит сам (или по скриншотам).

Папка результатов: `~/ai-visibility-research/<YYYY-MM-DD>/` (или куда скажет пользователь). Каждый факт — с датой снятия, сетью (RU / VPN) и режимом (с аккаунтом / без).

## 1. Первый шаг — стоит ли вообще

Прежде чем углубляться, оцени (по Вебмастеру/Метрике или по `site:` и позициям):
- сайт в индексе Яндекса и есть ли трафик из поиска;
- есть ли по нише запросы, на которые Алиса отвечает **с источниками** (а не генерирует текст сама и не молчит).

Если посадочные не в индексе или поискового трафика почти нет — главная работа «под ИИ» и есть обычное SEO в Яндексе + внешние площадки (Дзен, VK, каталоги). Скажи это прямо и сократи ИИ-часть до гигиены сущности бренда и месячного замера. Честная планка: у малых сайтов ИИ даёт единицы–десятки визитов в месяц на горизонте 3–6 месяцев.

## 2. Как работать

- **Параллельно, где нет общей зависимости.** Обзор, аудит (curl), сверка цифр, офлайн-анализ — независимые агенты в фоне. Браузер: Яндекс — одним агентом в одном окне; чаты ИИ можно параллельно, но **в отдельном окне** (фоновые вкладки Chrome тормозит, чтение зависает).
- **Браузер.** Chrome пользователя по CDP. Текст — коротким `innerText` после `bringToFront()`, без циклов опроса внутри страницы. Если подключение висит ~30 с дважды — Chrome ждёт разрешения на отладку: попросить пользователя нажать «Разрешить».
- **Яндекс без капчи и без искажений** (подробности — `knowledge.md`, «Как снимать Яндекс»):
  - российский IP без VPN (проверить `ipinfo.io` в начале и в конце);
  - базовая линия — **чистый контекст без аккаунта**; аккаунт владельца завышает органику и персонализирует чат Алисы;
  - вся серия в **одном окне** (капча — на каждое новое окно), паузы 2,5–5 с, перед 2-й страницей 2–4 с;
  - при капче — вывести окно вперёд и сразу попросить пользователя пройти её, ждать до 15 мин;
  - ответ под плашкой «необычная активность» раскрывать «Показать ответ» и ждать, пока текст перестанет расти;
  - ждать по признакам (появился блок / ссылки), а не фиксированными паузами; скриншоты — только при аномалиях.
- **Мерить сериями**: появление блока ИИ нестабильно — минимум 2 прогона на запрос для статуса, 3–5 для выводов о стабильности.
- **Запросы — из спроса, а не из УТП сайта**: часть набора — частотные вопросные/рекомендательные фразы из Вордстата; запросы, повторяющие описание продукта, помечать.
- **Не выдумывать цифры.** Что не снялось — так и писать. Частоты только из Вордстата.
- **Не трогать код и деплой**, если код ведётся в другом месте или не согласовано. **Только чтение** в кабинетах до согласования. SSH и логи — только с явного разрешения.
- **Сайт может меняться во время исследования** — фиксировать время замеров и не смешивать «до» и «после».

## 4. Эксперименты

Проверять находки на нише пользователя, а не пересказывать литературу. Без правок сайта:
- **Процитированные vs непроцитированные** в одном топе: позиция, оформление, разметка, свежесть, объём, тип страницы. Обязательно сравнение **внутри «запрос × полоса позиций»** (Кохран–Мантель–Хензель или перестановки) и поправка на множественные сравнения — иначе тип страницы и позиция маскируются под эффекты.
- **Персонализация**: те же запросы с аккаунтом и без.
- **Стабильность**: 3–5 прогонов, Жаккар по URL и доменам, частота появления блока.
- **Глубина**: органика до 20–30-й позиции, где стоят процитированные URL.
- **Длинный сценарный запрос vs короткий** (подвопросы): состав источников, частота блока.
- **Регион**, **чат Алисы vs блок в выдаче**.
- **Ассистенты без домена в вопросе** — есть ли у них сайт в индексе.
- **Логи сервера** (с разрешения): подлинные ИИ-боты (по IP-спискам), `llms.txt`, ChatGPT-User / Perplexity-User, визиты ассистентов в момент вопросов, рефереры из ИИ; свои IP и сторонние «чекеры» исключать.

С правками сайта — **только план на согласование**: гипотеза, опытные и контрольные страницы, метрика (ручной замер сериями без аккаунта + отчёт Вебмастера), срок (переиндексация — дни–недели).

## 5. Критики

Три независимых агента после сбора данных; давать им **файлы, а не свои выводы**:
1. **Методолог** — выборки и мощность, повторяемость, корреляция ≠ причина, смещение отбора запросов, персонализация, VPN, изменения сайта в ходе замеров; перепроверка по сырым данным.
2. **Источники и цифры** — каждая цифра → первоисточник; доля запросов ≠ аудитория ≠ доля трафика; даты; пересказы.
3. **Адвокат дьявола** — применимость к РФ и к типу продукта (Telegram-бот, сезонный сервис, SaaS, контентный сайт), альтернативные объяснения, что навредит или не окупится, что упущено (Дзен, VK, Пикабу, каталоги, Яндекс Бизнес), правовые риски.

Затем — перепроверка спорного (этап 10) и правка итогов. Опровергнутое явно вынести в таблицу «было → стало».

## 6. Итоговые файлы

**`00-REPORT.md`**:
1. Что установлено (с основанием и уровнем) и что опровергнуто (таблица «было → стало»).
2. Статус каждого сайта без аккаунта: ответ Алисы / органика / индекс / Вебмастер / Bing / GigaChat / DeepSeek / ИИ-переходы.
3. **План на согласование** с честной оценкой эффекта каждого пункта; «не делать».
4. **Регламент — раз в месяц, 30–40 минут:**
   - Вебмастер → Эффективность → **Видимость сайта в Алисе AI** (SoV, список запросов) и индексация;
   - ручной замер Алисы без аккаунта: 3 запроса на сайт × 2 прогона; GigaChat: 3 запроса + брендовый (верны ли факты);
   - ИИ-переходы: рефереры alice.yandex.ru, chatgpt.com, perplexity.ai, giga.chat, chat.deepseek.com, `utm_source=chatgpt.com` (без yandex.ru/ya.ru — клики из блока Алисы там не отличить); для Telegram-ботов — `?start=`-метки;
   - **Bing Webmaster** — подключить (импорт из Google Search Console, sitemap), дальше раз в квартал Search Performance и AI Performance;
   - сезонно — Вордстат по сезонным кластерам; раз в квартал — содержательное обновление сравнительных страниц;
   - журнал замеров с первой строкой «сейчас». Если за 3 месяца ИИ-переходы остаются единицами — закрыть отдельный «ИИ-трек» и оставить SEO + сущность бренда.
5. Что осталось неизвестным.

**`site-<домен>.md`**: где сейчас (факты с датой и режимом замера), спрос, план с ожидаемым эффектом, «не делать», 3–4 запроса для месячного замера, критерии успеха (в т. ч. упоминания в отчёте «Видимость в Алисе AI», верное описание бренда ассистентами, сайт в Bing Webmaster).

**Обязательные блоки в рекомендациях:**
- **Сущность бренда**: «Имя (домен) — тип продукта» на главной, в подвале и на 2–3 внешних страницах; Organization с `alternateName`. Ассистенты выдумывают описания малоизвестных брендов — это самый дешёвый способ снизить вред.
- **Правовой блок (РФ)**: сравнения с конкурентами и «лучший» — по 38-ФЗ только с критерием и проверяемо; своя подборка — с пометкой «наш сервис», критериями и датой сверки цен; платные размещения — маркировка.

В ответе пользователю — итог, а не пересказ файлов: что подтвердилось и опровергнулось, статус сайтов, что предлагается сделать (на согласование), где лежат файлы.
