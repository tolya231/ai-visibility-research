# ai-visibility-research — скилл для Claude Code

Исследование «как сайту попадать в ответы и рекомендации ИИ» для российской аудитории: Алиса AI в поиске Яндекса, GigaChat, DeepSeek, затем ChatGPT и Perplexity.

Что делает скилл:
- обзор статей и справки Яндекса с уровнем доказательности каждого вывода;
- спрос по Вордстату, в том числе вопросные и «рекомендательные» формулировки;
- живые ответы Алисы, GigaChat и DeepSeek: кого называют, какие источники цитируют, где ваш сайт;
- аудит сайта глазами ботов;
- сверку чужих цифр (статей и ответов других нейросетей) с первоисточниками;
- эксперименты, три агента-критика и перепроверку спорного;
- итог: отчёт, план по каждому сайту и регламент замеров раз в месяц.

Без браузера и доступа к Вебмастеру скилл работает в облегчённом режиме: обзор, аудит через curl, сверка цифр и готовые списки запросов для ручной проверки.

## Установка

```bash
git clone https://github.com/tolya231/ai-visibility-research.git /tmp/ai-visibility-research && mkdir -p ~/.claude/skills && cp -R /tmp/ai-visibility-research/ai-visibility-research ~/.claude/skills/
```

Затем в Claude Code: `/ai-visibility-research` или просто «как попасть в выдачу Алисы с моим сайтом example.ru».

Обновление — та же команда после `rm -rf /tmp/ai-visibility-research`.

## Что внутри

- `ai-visibility-research/SKILL.md` — порядок работы;
- `ai-visibility-research/references/knowledge.md` — что уже известно (ноябрь 2026), с уровнями доказательности; перепроверяйте пункты старше 3 месяцев;
- `ai-visibility-research/references/agent-briefs.md` — постановки для агентов.

Выводы получены на небольшой выборке (3 сайта, ~45 запросов, ноябрь 2026). Это пилот, а не отраслевая статистика.
